# 资料提供方的格式

`/screenings/inbox.html` 为制片交付登记，列为母版、时长秒、视频件、字幕件、发行用途。登记不表示授权。`/permissions/r1.json` 与 `/permissions/r2.json` 给出评审轮次、代号、母版、视频许可、字幕许可、资格结束分钟。purpose=house 表示资料室，目的与盲审不同。r2.changed 是生效后更改，revocations 给出范围（用途、物件、到期分钟）。已提交评语索引可从 `/office/seen.csv` 获取。
`/media/items.json` 的 artefacts 包含物件、对应母版或 shared、类型、署名可见及相对下载 URL。提供小型合成介质占位件，合约以实际 HTTP 取件字节为准。M2 的版本授权已登记时，一个无署名字幕尚未发布，晚到件由 `/media/addendum.json` 发现。
`/office/panels.csv` 给办公室对评委、组与展示代号的资格审定，deny 与 allow 仅适用于对应组合。
